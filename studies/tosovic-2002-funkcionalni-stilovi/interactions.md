# Interaction with existing project evidence

## Existing `editing`

This source provides the strongest general theoretical foundation so far for the `editing` layer.

It adds:
- style as selection + organization;
- task/audience/channel before surface cleanup;
- explicit separation of stylistic norm from language norm;
- five broad functional-style profiles plus interstyles/substyles/genres;
- economy vs redundancy as a functional balance;
- productive style switching.

**Decision:** integrate as the general register model rather than creating one reviewer per functional style.

## Interaction with Panić Kavgić 2019

Panić Kavgić establishes that pragmatic directness, mitigation and interactional markers depend on relationship/context.

Tošović generalizes the architecture upward: relationship is one part of a broader functional-style system involving activity, genre, audience and channel.

**Combined rule:** local pragmatic form must be evaluated inside a functional-style/genre profile.

## Interaction with Pavlović Jovanović 2026

Pavlović Jovanović gives a modern focused account of legal language. Tošović provides the broader administrative-style framework and explicitly treats standardization/unification as central.

**Combined rule:** legal/administrative repetition, passive/impersonal structures and formulas require register-aware interpretation; Pavlović Jovanović remains the more specific source for legal boundaries.

## Existing `ai_style`

This source is a major false-positive boundary for structural AI diagnostics.

It explicitly treats:
- standardization;
- unification;
- recurring formulas/clichés;
- regular document structure

as functional in some administrative/publicistic genres.

**Decision:** do not remove existing document-level AI signals, but require genre-aware interpretation and document that administrative forms/templates and conventional publicistic scaffolds can be legitimate counterexamples.

## Existing `native_usage`

The conversational chapter supports preserving ellipsis, fragments, repetitions and interactional economy in conversational contexts. Because the source is from 2002 and uses broad cross-Yugoslav evidence, these are model-level tendencies pending modern corpus calibration.

## Existing `serbian_norm`

No hard rule is added. The book's own distinction between stylistic and language norm supports keeping this boundary strict.

## Existing bureaucratic/legal guidance

No conflict. Tošović strengthens the existing rule that standardization and formulaicity can be functional, while Pavlović Jovanović supplies the sharper modern legal-language boundary.

## Source conflicts

No material conflict with current integrated studies. The main risk is overgeneralization from broad functional-style abstractions; therefore all new runtime guidance remains model-based.
