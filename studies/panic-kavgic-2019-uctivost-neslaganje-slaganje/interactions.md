# Interaction with existing project evidence

## Existing `native_usage`

The library is currently `PROJECT` and has no operational rules. This source provides its first substantial pragmatic evidence: directness, mitigation, discourse markers, address, pragmatic clarity and context.

**Decision:** enrich the long-lived `native_usage` model; do not create a separate “politeness reviewer”.

## Existing `interference_en`

The library is currently `PROJECT`. Existing public-source work is mostly lexical/contact-oriented (Prćić). Panić Kavgić adds a different layer: **pragmatic transfer**.

Complementary phenomena:
- excessive English-like indirectness/face-management in otherwise neutral Serbian;
- transfer of interactional packaging;
- loss or distortion when translating interpersonal markers.

**Decision:** keep these distinct from lexical anglicisms but under the same English-interference library.

## Existing `editing`

The source strengthens the rule that factual preservation is insufficient if an edit changes interpersonal force, familiarity or formality.

**Decision:** add model guidance to preserve functional particles, hedges, vocatives and purposeful repetition.

## Existing `ai_style`

No source claim supports AI-authorship inference.

**Decision:** no new `AI_STYLE_SIGNAL`. English-like pragmatic packaging belongs to `INTERFERENCE`, not AI detection.

## Interaction with future corpus calibration

A general Serbian corpus may validate lexical/discourse-marker distributions, but frequency cannot resolve all pragmatic functions. Dialogue-specific or conversational corpora would be preferable for calibration.

## Conflicts

No hard conflict with current runtime rules. The main corrective is against a possible future overgeneralization: “indirect = polite/natural” and “particles = filler” must both remain prohibited shortcuts.
