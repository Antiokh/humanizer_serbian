# Source studies

Every substantial Serbian source should be processed here before its claims enter a runtime library.

For each source create a dedicated folder containing, as applicable:

- `source.md` — bibliographic identity, edition, access/licensing notes and scope actually available to the project;
- `claims.jsonl` — formalized observations with source location/provenance;
- `counterexamples.jsonl` — cases where naive generalization would be wrong;
- `norm_audit.md` — whether historical/editorial advice agrees with current Serbian norm;
- `evals.jsonl` — project-authored positive, negative and boundary examples;
- `integration.md` — target library, phenomenon IDs and proposed automation level.

Rules:

1. Do not reconstruct missing chapters or inaccessible text from tables of contents.
2. Publicly readable copyrighted books are research sources, not content to copy into the repository.
3. A source observation is not automatically a language rule.
4. Repeated mechanisms should enrich one long-lived library rather than create duplicate reviewer voices.
5. Source conflicts remain explicit until resolved by stronger evidence or scope distinctions.
